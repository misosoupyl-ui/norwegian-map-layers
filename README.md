# Kartbasert Webapplikasjon - KWS2100
### This application is made for exploring different maritim geographics data. You have the ability to toggle on/off different datasources.

## Features
- [x] Switch between different tile layers
- [x] Clik on the points to see properties
- [x] Hover over municipality to see the property name
- [x] Toggle on/off datasources
